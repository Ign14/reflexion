# Sistema de maquetación — Volumen 1

**Estado:** especificación editorial inicial 0.5. La exportación PDF integral y su revisión visual siguen pendientes.

## Formato
- Página A4 vertical, márgenes generosos y numeración exterior inferior.
- Portada con título de la colección, «Volumen 1 — Los cimientos invisibles», edición y fecha.
- Sumario navegable y páginas preliminares: propósito, cómo estudiar, límites éticos.
- Capítulos con número, pregunta guía, objetivos, explicación, diagramas, caso, actividad, evaluación y referencias.
- Apéndices: glosario, laboratorios, evaluación integral y bibliografía.

## Sistema tipográfico
- Fuente sans legible para cuerpo, tamaño orientativo 10.5–11 pt y entrelínea 1.35–1.5.
- Encabezados con jerarquía consistente; código monoespaciado.
- Color sobrio azul carbón y acento celeste, sin depender del color para transmitir significado.
- Tablas con texto ajustado, encabezados repetidos y sin filas truncadas.
- Diagramas vectoriales cuando sea posible, con descripciones textuales equivalentes.

## Elementos pedagógicos
- «Pregunta guía» al inicio.
- «No confundir» para errores frecuentes.
- «Caso empresarial» para aplicación.
- «Comprobación» para aprendizaje.
- «Reflexión» al cierre.

## Control de calidad previo a publicar
1. Revisar terminología, estándares y enlaces.
2. Normalizar tablas, ejemplos y citas.
3. Construir índice, referencias cruzadas y marcadores.
4. Generar PDF desde fuente versionada.
5. Renderizar todas las páginas y revisar cortes, viudas, tablas y figuras.
6. Verificar texto seleccionable, metadatos y enlaces.
7. Publicar artefacto con número de versión y changelog.

**No declarar el PDF como definitivo sin revisión visual y técnica completa.**
