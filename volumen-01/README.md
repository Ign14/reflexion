# Volumen 1 — Los cimientos invisibles

## Resultado de aprendizaje
Al finalizar, el lector podrá **seguir el trayecto de un dato** entre hardware, red local, proveedor de internet, servicios intermedios y aplicación; reconocer límites de confianza y plantear medidas defensivas con evidencia.

## Ruta sugerida
Leer los capítulos en orden, mantener un diagrama personal de red, completar el laboratorio y responder la evaluación. Repetir las observaciones desde una conexión cableada y una Wi-Fi propia si se dispone de ambas.

**Regla de oro:** la visibilidad de una red no equivale a permiso para inspeccionar comunicaciones de terceros.
